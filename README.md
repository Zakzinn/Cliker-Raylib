# Cliker-Raylib

# 🖱️ Raylib Clicker

Meu primeiro jogo de Clicker feito em **C++ usando Raylib**.

## 🎮 Sobre o jogo

Um jogo simples onde o objetivo é ganhar o máximo de pontos possível clicando em um botão.

Cada clique no botão principal adiciona **1 ponto**.

O jogo também possui um sistema de **Upgrades**:

- 💰 O primeiro upgrade custa **25 pontos**
- ⬆️ Cada upgrade dobra a quantidade de pontos ganhos
- 💸 O preço do próximo upgrade também dobra a cada compra

## 🕹️ Como jogar

1. Clique no botão para ganhar pontos.
2. Junte pontos suficientes para comprar um Upgrade.
3. Compre o Upgrade para aumentar seus ganhos.
4. Continue clicando e comprando upgrades!
